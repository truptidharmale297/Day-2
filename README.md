Day 2 - Python Programming

Project Overview

This project is part of my Python training assignment. It includes Python basics, an Employee Management System, and CSV/JSON data analysis.

Technologies Used

- Python
- Visual Studio Code
- Git and GitHub
- CSV and JSON

Features

1. Python Exercises

- Variables and data types
- Lists, tuples, sets, and dictionaries
- Conditions and loops
- Functions and lambda expressions
- List comprehension
- Exception handling
- File handling
- Classes and objects

2. Employee Management System

- Add, update, and delete employees
- Search and list employee records
- Filter employees by department
- Sort employees by name or salary
- Calculate salary statistics
- Store employee records in JSON

3. CSV and JSON Data Analysis

- Count records
- Identify missing values and duplicates
- Calculate averages, minimums, and maximums
- Count records by department

Project Structure

- "python-exercises/" - Python practice programs
- "management-system/" - Employee Management System
- "csv-analysis/" - CSV and JSON analysis

Requirements

- Python 3
- Visual Studio Code (recommended)

How to Run

Run Python exercises:

python .\python-exercises\python_basics.py

Run Employee Management System:

python .\management-system\employee_management.py

Run CSV and JSON analysis:

python .\csv-analysis\csv_analysis.py

Learning Outcomes

Learned Python fundamentals, file handling, exception handling, JSON storage, and basic data analysis.

Conclusion

This project helped me practice Python programming and develop practical problem-solving skills.
